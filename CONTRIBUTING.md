# Contributing to vue-pdf-embed

Thank you for considering contributing to **vue-pdf-embed**. We appreciate your time and effort in helping improve this project.

## Bug reports and feature requests

Please use [GitHub issues](https://github.com/hrynko/vue-pdf-embed/issues) to report bugs or request new features. When opening an issue, provide as much information as possible, including:

- Expected and actual behavior
- Steps to reproduce the problem
- Environment details
- Screenshots or code samples, if applicable

Clear reports help maintainers and contributors understand and resolve issues more effectively.

## Proposing features and submitting fixes

All code contributions should be submitted through [pull requests](https://github.com/hrynko/vue-pdf-embed/pulls). When creating a PR:

- Provide a clear description of the change
- Link any related issue(s)
- Keep changes focused and atomic
- Ensure the code passes linting and builds successfully
- Add or update unit tests when applicable

We warmly welcome your improvements, features, and bug fixes.
